# Smart Canteen Ordering System

The **Smart Canteen Ordering System** is a simple and responsive web application developed using **HTML, CSS, and JavaScript**. It allows students to browse the available food items, add their favorite items to the cart, view the total price, remove items, and place an order easily. The project provides a clean and user-friendly interface that demonstrates basic web technologies and JavaScript-based cart functionality.

### Live Demo

[Smart Canteen Ordering System](http://127.0.0.1:5500/#menu)

This project is designed as a Web Technology mini project to demonstrate frontend development, responsive design, user interaction, and dynamic content handling using JavaScript.
